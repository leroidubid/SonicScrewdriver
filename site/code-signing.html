Code signing policy

Status: releases are not code-signed yet. The project has applied to the SignPath Foundation for free code signing; this page describes how releases will be signed once it is granted. Until then, check a download with its build attestation and SHA256SUMS.txt.

What is signed

The portable SonicScrewdriver.exe and the installer SonicScrewdriver-Setup-x.y.z.exe of each stable release. Only binaries built by the release workflow from the tagged commit of this repository are submitted. Pre-releases are not signed.

Roles

  • Committers and reviewers: Remi Chanoine (maintainer). Changes reach main through pull requests that need passing checks.
  • Approvers: Remi Chanoine. Every signing request is approved by hand in SignPath; nothing is signed automatically.

The maintainer's accounts on GitHub and SignPath use multi-factor authentication.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The only network request is the update check, which runs when you click “Check for updates” or when you turn on “Check at startup” (off by default); it sends no identifier. See Security for what the app reads and stores.
