Download

Download for Windows

The button opens the latest release on GitHub. Released . Direct links: Installer · Portable exe

Requirements

  • Windows 10 version 1809 or later, 64-bit. See which systems were tested: Windows 10 22H2 is the only one checked so far, Windows 11 is not tested yet.
  • The .NET 8 Desktop Runtime, if you do not have it (the installer checks and links to it).

Which file?

On the Releases page, download either:

  • SonicScrewdriver-Setup-x.y.z.exe: per-user install, no admin rights, Start menu shortcut, optional start with Windows, clean uninstall, available in English, French, German, Spanish, Italian and Brazilian Portuguese (it follows the Windows display language);
  • or SonicScrewdriver.exe: portable, just run it.

Then right-click the tray icon, choose Settings, and add your shortcuts. Settings are stored in %APPDATA%\SonicScrewdriver\settings.json.

SmartScreen warning

Windows SmartScreen may warn on first run because the files are not code-signed: click More info, then Run anyway. Some antivirus engines may also flag the files: see antivirus false positives.

Verify your download

  • Releases are built by GitHub Actions from the tagged commit and come with SHA256SUMS.txt: compare the hash of your file with it.
  • You can check that a download was built from this repository (needs the GitHub CLI):
gh attestation verify SonicScrewdriver-Setup-x.y.z.exe --repo leroidubid/SonicScrewdriver

More on the build and scan chain: Security.

Uninstall

The installer provides a clean uninstall. The portable exe has nothing to uninstall: quit it from the tray menu and delete the file. Settings stay in %APPDATA%\SonicScrewdriver until you delete that folder yourself.

Build it yourself

The source is on GitHub (source-available: MIT + Commons Clause). Building requires the .NET 8 SDK; the build commands are in the README.
