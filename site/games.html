Games and anti-cheat

An honest statement

Sonic Screwdriver is not a cheat: it installs no driver, injects nothing into other programs and never reads their memory. Even so, anti-cheat systems are opaque, and a global keyboard hook can look suspicious to some of them, so compatibility cannot be guaranteed.

Competitive mode

For online games with strict anti-cheat (Vanguard, FACEIT, EasyAntiCheat, BattlEye), turn on Competitive mode (tray menu, or Settings) or quit the app first. In that mode:

Switched offWhat you lose
The keyboard hookAll modifier + media key shortcuts, remapped media keys, and output device cycling
The on-screen displayThe overlay shown after a shortcut
Mouse wheel on the tray iconMaster volume with the wheel
Lookups of other programsApp icons and friendly names (the exe name and a generic icon are shown instead)
Observers and extra shortcutsAutomatic ducking, streamer mode, microphone shortcut and mixer section, remembered routing, the output priority list, the now-playing line, the maximum-volume watch, program-start profiles, the mute-everything and profile shortcuts, and the command line (except --toggle-competitive)

The mixer, the sliders, switching the default output and the physical media keys keep working. Competitive mode lowers the risk but does not remove it: quitting the app is the safest choice.

Automatic mode

Off by default. In the settings you can list the games to protect: while a ticked program runs, competitive mode turns on by itself, and it turns off again when the program exits. A program is spotted by its exe name in the Windows process list, read from one snapshot every 5 seconds: the process is never opened, so no handle or access right touches the game. Nothing runs while the list has no ticked program. If you switch the mode yourself, the automation steps aside: a mode you turned on stays on, and one you turned off stays off until the program has exited. An automatic “on” is not saved as your preference.

Toggle shortcut

In the settings you can assign a key combination (for example Ctrl+Alt+F9) that switches competitive mode on and off, with a short notification each time. It has to work while the keyboard hook is uninstalled, so it does not use a hook: it is registered with the Windows RegisterHotKey function, where Windows itself matches the combination and tells the app. The app never sees any other key.

The trade-off: this is a documented, ordinary API that many programs use and is much less intrusive than a hook, but it is still one registration that stays active in competitive mode. If you want nothing at all, leave the shortcut empty (the default) and use the tray menu, or quit the app.

Tested systems

“Tested” means tried by the author; “Not yet” means not tested yet. The installer asks for Windows 10 version 1809 or later and the app is built for 64-bit Windows.

  • Windows 10 22H2 (build 19045): tested
  • Windows 11: not yet
  • Windows 10, older versions (1809 to 21H2): not yet
  • Windows 11 on ARM (runs through x64 emulation): not yet

The default device change and the per-app output use undocumented Windows interfaces, so a new Windows build can break them: please open an issue with your Windows version.
