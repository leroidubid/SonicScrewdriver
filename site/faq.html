FAQ

Why does it use a keyboard hook?

The shortcuts live on the media keys with a modifier (Shift + Vol−), and the app has to see those keys to act on one app instead of the whole system. The hook only looks at the six media keys and the keys you choose to remap to them; no other key is read or stored. Shortcuts on other keys (free shortcuts) use the Windows RegisterHotKey function instead, with no hook. More on security.

Is it a cheat?

No: it installs no driver, injects nothing into other programs and never reads their memory. Anti-cheat systems are opaque, though, and a global keyboard hook can look suspicious to some of them, so compatibility cannot be guaranteed. For online games with strict anti-cheat, turn on Competitive mode or quit the app. Games and anti-cheat.

Does it work in full-screen games?

That is the reason it exists: changing the volume of several apps quickly while a game runs full screen, without leaving the game. The shortcuts act on the media keys, so the game keeps focus. For games with strict anti-cheat, see Competitive mode, which switches the hook and the overlay off.

Why does Windows SmartScreen warn me?

The files are not code-signed. Click More info, then Run anyway. You can check the download against SHA256SUMS.txt and verify the build attestation: see Verify your download. A few antivirus engines also flagged an early build: antivirus false positives.

Can I set the volume of one browser tab?

Not with Sonic Screwdriver: all tabs and installed web apps of a browser share a single volume, because the browser plays all their audio through one process. Two ways around it:

  • Add a browser extension that gives each tab its own volume, such as Volume Manager (Chrome) or Per-Tab Volume Control (Firefox). They are separate projects that Sonic Screwdriver does not include and has not tested, and each has its own limits (for example, Volume Manager cannot toggle full screen on a tab it controls).
  • Play the game and the music in two different browsers: each one then has its own entry in the mixer.

Extensions that capture the sound of a tab ask for wide permissions, and an extension can change owner or behavior after you install it. Check its permissions, its reviews and its author before installing one.

Does it work on Windows 11?

It is built for Windows 10 and 11, but only Windows 10 22H2 (build 19045) has been tried by the author so far. Windows 11 is not tested yet. The default device change and the per-app output use undocumented Windows interfaces, so a new Windows build can break them: please open an issue with your Windows version. Tested systems.

My keyboard has no media keys.

Remap them: in the settings, choose which key acts as Vol+, Vol−, Mute, Play/Pause, Next and Previous (for example F10, F11, F12), or use free shortcuts on any key combination. Remap the media keys.

Shortcuts do nothing when an administrator window is in front.

When an elevated window has focus, Windows does not pass keys to the app unless it runs elevated too.

Where are the settings stored?

In %APPDATA%\SonicScrewdriver\settings.json.

How do I uninstall it?

The installer provides a clean uninstall. For the portable exe, quit it from the tray menu and delete the file. Details.

Does it use the network or collect data?

Not on its own. The only request is the update check, which you start with a button in Settings (or tick to run at startup, off by default, and never in competitive mode): it asks GitHub for the latest release, so GitHub sees your IP address, and nothing else is sent. The app collects nothing. This website does not use analytics or load anything from a third party.
