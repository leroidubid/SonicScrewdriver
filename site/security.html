Security

What it reads, what it sends

The keyboard hook only looks at the six media keys, and the keys you choose to remap to them (none by default); no other key is read or stored. The app makes no network request unless you ask for an update check (a button in Settings, or the optional check at startup), and collects nothing.

The optional competitive-mode toggle shortcut and the free shortcuts do not use the hook at all: they use the Windows RegisterHotKey function, where Windows matches the combination itself. See Games and anti-cheat.

To lower the footprint further, the app opens other programs with the minimal access right only: it reads their path, and app names and icons come from the file on disk. It does not request the right to read their memory (changelog 1.0.0).

How releases are built

Releases are built by GitHub Actions from the tagged commit, scanned with Microsoft Defender and VirusTotal (the report links are added to the release notes), and come with SHA256SUMS.txt.

Checksums

Compare the hash of your download with SHA256SUMS.txt from the same release.

Attestation

You can check that a download was built from this repository (needs the GitHub CLI):

gh attestation verify SonicScrewdriver-Setup-x.y.z.exe --repo leroidubid/SonicScrewdriver

Antivirus false positives

The files are not code-signed, and a few machine-learning engines on VirusTotal (for example SecureAge and Acronis) flagged an early build as suspicious, while Microsoft Defender and the other engines found nothing. These engines react to the API calls any keyboard-shortcut tool needs (a keyboard hook, key injection, start with Windows), not to anything harmful. To check a download yourself, compare its hash with SHA256SUMS.txt, verify the attestation above, or read and build the source. Because the files are not code-signed, Windows SmartScreen may also warn on first run (what to do).

Report a vulnerability

Please do not open a public issue for a security problem. Use GitHub private vulnerability reporting: open the Security tab of the repository and choose Report a vulnerability.
